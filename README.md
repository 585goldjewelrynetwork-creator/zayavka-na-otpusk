# Заявка на отпуск — учебный тренажёр

Тренажёр для практики «Сломайте мой тренажёр» к докладу «Пять ошибок в вайбкодинге».

Задание: оформить отпуск на вымышленном HR-портале и найти, где тренажёр ведёт себя странно или ломается. Ошибки заложены специально.

Компания «Ромашка» и все люди вымышлены. Данные никуда не отправляются: всё хранится только в вашем браузере до закрытия вкладки.
